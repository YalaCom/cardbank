# LumaCard demo

Светлый адаптивный демонстрационный сайт-розыгрыш с вымышленными виртуальными картами.

## Что внутри

- четыре сценария карт и несколько виртуальных регионов;
- мобильная и десктопная адаптация;
- фильтры по назначению карты;
- модальное подтверждение и финальный экран розыгрыша;
- без базы данных, аналитики и API;
- форма запрашивает только имя и телефон, не отправляет и не сохраняет их;\n- значения полей очищаются до показа финального экрана;
- автоматический деплой через GitHub Pages workflow.

> Это развлекательный макет, а не банк или платёжный сервис. Реальные карты не выпускаются. Форма работает только внутри вкладки: нет базы, cookies, localStorage, sessionStorage, аналитики и сетевых запросов.
